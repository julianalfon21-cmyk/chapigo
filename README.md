# ChapiGo

Sistema de orientación y descubrimiento para Chapinero Central. Esta versión es un piloto en el barrio Lourdes (Bogotá).

**Abrir la app:** https://julianalfon21-cmyk.github.io/chapigo/

- En Android, toca **Instalar app** y confirma.
- En iPhone, abre el enlace en Safari, toca **Compartir** y luego **Agregar a inicio**.

## Créditos
